### How to launch
1. Download `RealityState-Hunting-Holographic.html`.
2. Open it in a modern browser.
3. Allow internet access so the Three.js library can load from the CDN.
4. Press the on-screen mission start button.
5. Use the in-game control hints for keyboard or touch controls.

### Compatibility
This is a standalone HTML file, but its 3D library is loaded externally. It is therefore not fully offline. Browser performance varies by device. Test on your target device before purchase; mobile performance and control feel can differ from desktop.
